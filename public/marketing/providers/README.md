# Marketing provider artwork

Collected 6 September 2026 for the disconnected, evaluation-only ecosystem. These marks do not imply an implemented connector or partnership. All files are local, passive SVGs with no script, external resource reference or network request at render time.

- `notion.svg`: official navigation mark from https://www.notion.com/; page CSS class removed; the official black CSS token is resolved to `#000` for standalone rendering. Geometry and white fills preserved.
- `zoom.svg`: official navigation wordmark from https://www.zoom.com/en/about/media-kit/; page CSS class removed, original `color="#0B5CFF"` preserved.
- `dropbox.svg`: official navigation asset linked from https://www.dropbox.com/branding — https://fjord.dropboxstatic.com/warp/conversion/dropbox/warp/icons/Dropbox-logo-nav.svg?id=d587e174-e284-42e8-a18c-85c0d8e57e9e ; unchanged artwork.

Existing Google, Microsoft, Salesforce, HubSpot, Pipedrive and Slack artwork is reused from `public/brands`. Microsoft 365, Outlook and Teams appear together as one evaluation family.
