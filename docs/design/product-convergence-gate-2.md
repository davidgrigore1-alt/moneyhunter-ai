## Runtime repairs

### Workflows

The local Documents/Workflows failures included a mismatched service JWT. The guarded local launcher obtains matching public/server credentials from the running local Supabase stack, validates localhost URLs and disables email/model providers. It does not edit the environment file, seed or reset data.

After correcting credentials, a real workflow test exposed missing service SELECT privileges on approval/CRM tables and an incorrect organizations table reference. The fix adds three narrow read-only service RPCs in the new 20260909090000 migration: pending-approval boolean, tenant-scoped company name and an approval decision envelope without its payload. Client execution is revoked. Existing table grants and RLS were not broadened. Server authorization, actor/state checks, idempotency and recovery remain in their original paths. Query errors fail closed.

The migration was applied only to verified local Supabase and registered in the migration integrity baseline. Historical migration bytes remain unchanged. No remote environment was migrated.

Browser proof: draft “Revizuire după avansarea etapei” was saved and tested against Meridian. One configured condition matched; the test created **zero plans and zero effects**. It remains inactive.

## Adversarial review

- Evidence Inspector receives authorized projections, performs no autonomous fetch/model call, keeps safe source navigation and does not present metadata as document/email content. Fresh document access still uses the existing authorization path.
- RPCs use an empty fixed search path, qualified relations, tenant predicates and service-only EXECUTE. No ownership-chain change or privileged client logic was introduced.
- Search retains permission checks, authenticated business-filtered queries and bounded results. Only product labels and document/action destinations changed.
- Prepared/approval views do not infer evidence, assign an owner, confirm revenue or execute anything on render. Existing decision forms and audit remain reachable.
- Charts preserve original currencies and estimated/confirmed distinctions; percentages describe record counts, not likelihood of winning.
- Evaluation-only integrations have no connect action. Available capability does not imply connected, authorized or fully synchronized account data.
